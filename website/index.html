Premier League Predictor

By Aren Khachikian · In development

A machine learning project using historical Premier League results, pre-match Elo ratings, and XGBoost to predict home wins, draws, and away wins.

Progress so far

  • Loaded and cleaned three seasons of match results.
  • Calculated chronological pre-match Elo ratings.
  • Tuned XGBoost using chronological cross-validation.
  • Achieved validation log loss of 1.0321, compared with a historical-frequency baseline of 1.0828.

Interactive predictions and league simulations are planned.

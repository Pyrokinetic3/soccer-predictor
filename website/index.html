How did the model do before launch? +

In a historical evaluation of 50 held-out 2026/27 matches, the model picked 23 results correctly (46%), compared with 18 (36%) for a historical-frequency baseline. Its log loss was 1.030 versus 1.117 for that baseline. Lower log loss means better probability predictions.

This is a small initial sample, separate from the public prediction history above. It does not guarantee future performance.
